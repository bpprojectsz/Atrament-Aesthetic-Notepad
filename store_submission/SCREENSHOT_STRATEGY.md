# Screenshot Strategy — Atrament

Screenshots must be **captured from a real running build** — this document
specifies the shot list, required sizes, and caption copy; it doesn't
substitute for actually producing the images. Capture each shot using the
device simulators/hardware listed below.

## Required sizes

| Device | Resolution | Store |
|---|---|---|
| iPhone 6.7" (15 Pro Max class) | 1290 × 2796 px | App Store (required) |
| iPhone 5.5" (8 Plus class) | 1242 × 2208 px | App Store (required for older device support) |
| iPad Pro 12.9" | 2048 × 2732 px | App Store (if iPad support is claimed) |
| Android phone | 1080 × 1920 px minimum | Play Store (required) |
| Android 7" tablet | 1200 × 1920 px | Play Store (if tablet support is claimed) |
| Android 10" tablet | 1600 × 2560 px | Play Store (if tablet support is claimed) |

## Shot list (in display order)

1. **Hero** — Full-bleed parchment paper texture, elegant rich text
   visible, faint gold scripture watermark in the corner. No UI chrome
   (status bar can stay, app bar cropped out) so the paper texture reads
   as the entire screen.
   *Caption: "Write with Ambient Inspiration"*

2. **Notebook grid** — Home screen with 4–6 notebooks visible, cream
   cards, Merriweather typography on notebook titles.
   *Caption: "Every note, beautifully organized"*

3. **Dark mode** — Note editor in Dark theme, espresso background, muted
   gold accents visible on the toolbar.
   *Caption: "Three considered themes, not just inverted colors"*

4. **Handwriting** — Handwriting canvas mid-stroke, pen toolbar visible
   showing at least 2 pen types and the color/stroke-width controls.
   *Caption: "Real handwriting, not just typing"*

5. **Settings / Remove Ads** — Settings screen showing the theme
   selector and the "Remove Ads" row, demonstrating there's no
   aggressive paywall.
   *Caption: "Free, genuinely — pay only to remove one small ad"*

6. **iOS only: Home screen widget** (if/when built — not in the current
   Phase 1–7 scope) — today's verse in calligraphic serif on the
   lock/home screen.
   *Caption: "A quiet verse, right on your home screen"*

## Localized screenshot notes

For non-English App Store/Play Store listings, at minimum re-capture shot
1 (hero) and shot 2 (notebook grid) with the device set to that locale, so
the visible UI text matches the listing language. Shots 3–5 can reuse the
English captures if translating all six isn't feasible at launch — captions
in the store listing itself should still be localized regardless via the
per-locale ASO metadata.

## Do not

- Include real device chrome/bezel frames unless using Apple's/Google's own
  official screenshot framing tools — hand-drawn device frames read as
  unpolished.
- Show placeholder/lorem-ipsum text in any note content — write a few
  genuine-feeling sample notes ahead of the capture session.
- Include the AdMob banner in any screenshot — it's not a feature to
  advertise, and interstitial-looking captures can trigger extra store
  review scrutiny.
